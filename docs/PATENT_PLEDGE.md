# Patent Pledge (Defensive)

Aether Protocol Contributors (“we”) publish this defensive patent pledge for version **1.2.x** of the Aether Protocol software and specifications in this repository.

## Pledge

To the extent we own patents that necessarily read on the **Compliant Implementation** of Aether Protocol 1.2.x as specified in `docs/` and implemented in this repository under Apache-2.0, we pledge **not to assert** those patents against anyone who:

1. Implements Aether Protocol in a manner compatible with the published specs, and  
2. Does **not** assert patents against our Compliant Implementations or against other Compliant Implementations for the purpose of blocking Aether Protocol interoperability.

## Termination

This pledge terminates automatically as to any party that files a patent claim alleging that a Compliant Implementation infringes, except for defensive counterclaims.

## Non-goals

- This pledge does **not** grant trademark rights.  
- This pledge does **not** replace Apache-2.0’s patent grant for Contributions.  
- This pledge is **not** a warranty of non-infringement of third-party patents.
