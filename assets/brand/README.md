# Aether Brand Kit

| Asset | Path | Use |
|-------|------|-----|
| Mark (SVG) | [`logo.svg`](logo.svg) | Favicon, app icon, README |
| Wordmark (SVG) | [`wordmark.svg`](wordmark.svg) | Docs headers, presentations |
| Raster mark | [`aether-logo.png`](aether-logo.png) | Social previews, GitHub og:image |

## Colors

| Token | Hex | Role |
|-------|-----|------|
| Ink | `#0b1c1a` | Background / primary surface |
| Teal | `#0f6b5c` | Secondary accent |
| Signal | `#c8f542` | Primary accent / CTA |
| Fog | `#e8f2ef` | Primary text |
| Mist | `#c5ddd6` | Secondary text |

## Clear space

Keep empty margin ≥ 1/8 of the mark height on all sides. Do not place on low-contrast backgrounds or recolor the signal lime arbitrarily.
