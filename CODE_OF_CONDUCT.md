# Contributor Covenant Code of Conduct

## Our pledge

We pledge to make participation in Aether a harassment-free experience for everyone.

## Our standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language  
- Being respectful of differing viewpoints  
- Gracefully accepting constructive criticism  
- Focusing on what is best for the community  

Unacceptable behavior includes harassment, trolling, insulting comments, and publishing others’ private information.

## Enforcement

Report issues via GitHub maintainers. Maintainers may remove contributions or ban contributors for behaviors that violate this code.
